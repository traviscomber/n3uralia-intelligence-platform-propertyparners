# Plantilla de aceptación de procedencia de datos

## Objetivo

Confirmar qué fuentes alimentan cada módulo y distinguir dato del Cliente, dato externo, transformación técnica e inferencia.

## Registro por fuente

- nombre de la fuente;
- propietario o proveedor;
- tipo de dato;
- módulo consumidor;
- frecuencia de actualización;
- período cubierto;
- método de ingreso;
- controles de calidad;
- restricciones de uso;
- responsable funcional;
- responsable técnico;
- estado: `pending`, `approved`, `restricted` o `deprecated`.

## Reglas

- No usar datos del Cliente para otros clientes ni entrenamiento sin autorización contractual.
- Las inferencias deben identificarse como tales y no presentarse como evidencia primaria.
- Las fuentes externas deben conservar referencia y fecha de obtención.
- CBR, ventas recientes y KML permanecen pendientes mientras no exista entrega y aprobación verificable.
