# Aprobación de calendario y automatizaciones de reportes

## Objetivo

Registrar la configuración operativa aprobada para reportes y automatizaciones. Este documento no autoriza envíos mientras los campos obligatorios permanezcan incompletos.

## Configuración por reporte

Para cada reporte registrar:

- nombre del reporte;
- objetivo;
- audiencia;
- período cubierto;
- frecuencia;
- día y hora;
- zona horaria;
- destinatarios principales;
- copias;
- remitente autorizado;
- canal de entrega;
- formato;
- regla de reintento;
- responsable de revisión previa;
- responsable de aprobación;
- excepción por feriados o cierres;
- fecha de inicio;
- fecha de término, cuando aplique.

## Regla mensual obligatoria

Los reportes mensuales sólo pueden cerrarse y enviarse como definitivos cuando el período esté completamente terminado. El mes en curso debe presentarse únicamente como avance, preliminar o período en progreso.

## Controles de autorización

Antes de activar una automatización se debe confirmar:

- destinatarios aprobados;
- capacidad o secreto cron requerido;
- datos de origen disponibles;
- período válido;
- vista previa revisada;
- asunto y cuerpo aprobados;
- ausencia de datos internos o errores técnicos expuestos;
- procedimiento de suspensión inmediata.

## Cambios posteriores

Todo cambio debe registrar:

- campo modificado;
- valor anterior;
- valor nuevo;
- motivo;
- solicitante;
- aprobador;
- fecha de entrada en vigencia.
