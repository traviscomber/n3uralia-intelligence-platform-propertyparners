## Exclusiones

No se consideran soporte correctivo automático:

- nuevos módulos o integraciones;
- cambios de reglas de negocio no aprobados;
- limpieza masiva de datos originados por el Cliente;
- costos o incidentes de terceros fuera del control acordado;
- problemas causados por credenciales, configuraciones o cambios no autorizados;
- ampliaciones de capacidad o volumen no contratadas.
