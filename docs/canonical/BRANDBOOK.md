# Brandbook canónico

Este documento define la identidad visual obligatoria de la aplicación y de los reportes de Property Partners Vitacura.

## Fuente de verdad

Los tokens técnicos vigentes se definen en `app/globals.css`. Este documento explica cómo deben usarse.

## Paleta principal

- Fondo principal: `#050807`
- Superficie: `#0c1111`
- Superficie secundaria: `#0f1616`
- Texto principal: `#edf4f3`
- Texto secundario: `#b6c1bf`
- Rojo corporativo: `#d7332b`
- Rojo accesible: `#ff766f`
- Azul informativo: `#1565c0`
- Verde positivo: `#27ae60`
- Naranja preventivo: `#f39c12`
- Gris neutral: `#7f8c8d`

## Semántica cromática

- Verde: objetivo cumplido o superado, cumplimiento igual o superior a 100%.
- Naranja: desempeño cercano a meta, entre 90% y 99%.
- Rojo: incumplimiento, brecha, alerta o riesgo, inferior a 90%.
- Azul: serie informativa, volumen o dato neutral.
- Gris: referencia, contexto, meta o dato secundario.

El rojo corporativo puede utilizarse en identidad, títulos, divisores y elementos estructurales. Nunca debe representar un resultado positivo.

Las metas deben presentarse como referencias neutrales, salvo que exista una alerta explícita asociada a ellas.

## Tipografía y composición

- Tipografía principal para reportes: Calibri.
- Respaldo compatible: Arial, sans-serif.
- Diseño sin radios decorativos en superficies principales.
- Evitar sombras, gradientes y efectos tecnológicos que compitan con la lectura ejecutiva.
- Mantener contraste alto y jerarquía clara entre título, indicador, contexto y conclusión.
- Las cifras deben usar formato chileno y numeración tabular cuando sea posible.

## Gráficos

- Cada color debe tener significado semántico estable.
- Los resultados positivos no deben mostrarse en rojo.
- Las metas deben utilizar gris o una línea neutral.
- Las series informativas pueden usar azul.
- Verde, naranja y rojo se reservan para estados de desempeño.

## Aplicación

Este brandbook aplica a:

- interfaz web;
- dashboard;
- reportes ejecutivos;
- vistas previas;
- correos enviados por Resend;
- documentos y materiales generados desde la plataforma.
