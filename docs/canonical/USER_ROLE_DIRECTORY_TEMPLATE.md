# Plantilla de directorio de usuarios, roles y capacidades

## Objetivo

Formalizar quién puede acceder a cada superficie de la plataforma y evitar altas o permisos basados en supuestos.

## Registro por usuario

- nombre completo;
- correo corporativo;
- organización o sucursal;
- cargo;
- rol funcional;
- capacidades requeridas;
- alcance de datos;
- fecha de alta;
- fecha de revisión;
- responsable aprobador;
- estado: `pending`, `active`, `suspended` o `revoked`.

## Reglas de control

- Aplicar mínimo privilegio.
- No compartir cuentas.
- Toda alta, baja o cambio debe tener aprobador y fecha.
- Usuarios inactivos o desvinculados deben revocarse.
- Los accesos administrativos y técnicos deben mantenerse separados de los accesos operativos.
- Los secretos y credenciales no se registran en este documento.
